# WebMe

**Research, publications & projects.**

一个简洁、双语的学术研究展示网站，将研究方向、最新论文与近期项目组织在同一页面，让访客快速了解研究主题、阅读成果并探索相关代码。

## 研究领域

| 方向 | 关注主题 |
| --- | --- |
| 智能传感 | 气体传感、温度调制、长期漂移与表征学习 |
| 半导体与物理建模 | 工艺建模、数值模拟与优化 |
| 临床机器学习 | 血液透析、纵向数据与外部验证 |
| 智能微流控 | 液滴识别、图像分割与路径规划 |

## 内容与体验

- **研究概览** — 从科学问题与应用场景出发，介绍各方向的研究重点。
- **论文索引** — 按年份展示学术论文，支持关键词搜索、主题筛选与 DOI 跳转。
- **便捷引用** — 查看、复制和下载 BibTeX 引用。
- **项目展示** — 汇集科研工具、仿真框架与实验平台，链接代码仓库或项目说明。
- **中英双语** — 一键切换主要内容与交互界面。
- **跨设备阅读** — 适配桌面、平板与手机，支持键盘导航和减少动态效果偏好。

## 视觉设计

受 Claude 风格启发，以暖米白为底色、陶土橙为点缀，结合衬线标题、清晰的内容层次和充足留白，突出研究内容与阅读体验。

## 技术特点

原生 **HTML · CSS · JavaScript**，无需前端依赖或构建工具。内容与交互保持轻量，论文引用提供独立 BibTeX 文件。
